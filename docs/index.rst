Rig Conductor
=============

**Rig Conductor** runs a heat-aggression recording from start to finish: record
on a loopbio Motif rig, cut the video into one clip per arena, track the flies
with SLEAP on an HPC cluster, score the behaviour, and copy the results to a USB
disk. A second wizard grows the labelled frames that teach the pose model and
trains new models on the cluster.

The user manual below is the same text the **Help** button (F1) opens inside
both wizards, and the one printed to the PDF.
